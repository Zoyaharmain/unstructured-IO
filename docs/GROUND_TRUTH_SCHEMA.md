# Ground Truth Annotation Schema Reference

This specification defines the ground-truth annotation format for the `unstructured-IO` resume parsing and block-detection pipeline. It is independent of production prediction schemas to ensure unbiased validation.

## Principles

1. **Authoritative Source Binding**: Annotations are strictly bound to the exact extracted source elements using the SHA-256 hash of all element text strings (`extraction_sha256`).
2. **Complete Source Coverage**: Every character in every extracted element must be assigned either to a canonical section category or marked as `ignore` (for layout artifacts, running headers/footers, watermarks, or pagination markers).
3. **Non-overlapping Intervals**: Intervals `[start, end)` for any given `source_element_index` must be strictly contiguous and non-overlapping.
4. **Verification Status**: Annotations are classified as:
   - `unverified` (draft candidate generated by rules/LLM proposal, `human_verified: false`)
   - `gold` (explicitly human-reviewed and approved, `human_verified: true`)
   - `silver` (automatically generated at scale across full corpus, `human_verified: false`)
   - `needs_review` (flagged for review due to low confidence, uncertainty, or parser conflicts)

## Canonical Categories

- `personal_information`: Candidate name, contact details (email, phone, address, location, links).
- `summary`: Career objective, professional summary, profile, about me.
- `experience`: Work history, roles, employers, job dates, responsibilities, client details.
- `education`: Degrees, institutions, colleges, graduation years, academic grades/GPA.
- `skills`: Technical proficiencies, tools, frameworks, core competencies.
- `projects`: Academic, personal, or technical side projects independent of employment.
- `certifications`: Professional licenses, certifications, courses, credentials.
- `awards`: Honors, competitive prizes, hackathons, merit awards.
- `publications`: Research papers, journal articles, books, conference proceedings, patents.
- `volunteering`: Unpaid charitable roles, community service, social leadership.
- `languages`: Spoken languages and proficiency levels.
- `interests`: Personal hobbies and extracurricular interests.
- `references`: Professional referees and contact details.
- `ignore`: Document artifacts, running headers/footers, page numbers, decorative tokens.

## Schema Specification (JSON)

```json
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "title": "ResumeGroundTruthAnnotation",
  "type": "object",
  "required": ["file", "extraction_sha256", "human_verified", "spans"],
  "properties": {
    "file": {
      "type": "string",
      "description": "Original resume filename (e.g. 'Pavan Bakku.pdf')"
    },
    "extraction_sha256": {
      "type": "string",
      "description": "SHA-256 hash of json.dumps([e['text'] for e in elements]) ensuring exact text alignment"
    },
    "human_verified": {
      "type": "boolean",
      "description": "True only if independently validated and approved by a human reviewer"
    },
    "reviewer": {
      "type": "string",
      "description": "Identifier of the reviewer or approval process"
    },
    "reviewed_at": {
      "type": "string",
      "format": "date-time"
    },
    "spans": {
      "type": "array",
      "description": "Full coverage span list. Every element character must belong to exactly one span.",
      "items": {
        "type": "object",
        "required": ["source_element_index", "start", "end", "category"],
        "properties": {
          "span_id": {"type": "string"},
          "source_element_index": {"type": "integer", "minimum": 0},
          "start": {"type": "integer", "minimum": 0},
          "end": {"type": "integer", "minimum": 0},
          "category": {
            "type": "string",
            "enum": [
              "personal_information", "summary", "experience", "projects",
              "education", "skills", "certifications", "awards", "publications",
              "volunteering", "languages", "interests", "references", "ignore"
            ]
          },
          "text": {"type": "string"},
          "page_number": {"type": "integer"},
          "coordinates": {"type": "object"},
          "uncertainty_flag": {"type": "boolean"},
          "uncertainty_reason": {"type": ["string", "null"]},
          "block_id": {"type": "string"},
          "record_type": {"type": ["string", "null"], "enum": ["work_experience", "education", "project", null]},
          "record_id": {"type": ["string", "null"]},
          "field_role": {
            "type": ["string", "null"],
            "enum": [
              "heading", "content", "employer", "title", "dates", "client",
              "responsibility", "degree", "institution", "year", "grade",
              "contact_field", "skill_item", "artifact", null
            ]
          }
        }
      }
    },
    "records": {
      "type": "object",
      "properties": {
        "work_experience": {
          "type": "array",
          "items": {
            "type": "object",
            "properties": {
              "record_id": {"type": "string"},
              "employer": {"type": "string"},
              "title": {"type": "string"},
              "dates": {"type": "string"},
              "client": {"type": ["string", "null"]},
              "responsibilities": {"type": "array", "items": {"type": "string"}},
              "span_ids": {"type": "array", "items": {"type": "string"}}
            }
          }
        },
        "education": {
          "type": "array",
          "items": {
            "type": "object",
            "properties": {
              "record_id": {"type": "string"},
              "degree": {"type": "string"},
              "institution": {"type": "string"},
              "year": {"type": "string"},
              "grade": {"type": ["string", "null"]},
              "span_ids": {"type": "array", "items": {"type": "string"}}
            }
          }
        }
      }
    },
    "metadata": {
      "type": "object",
      "properties": {
        "source_pdf_sha256": {"type": "string"},
        "page_count": {"type": "integer"},
        "total_elements": {"type": "integer"},
        "selection_rationale": {"type": "string"},
        "version": {"type": "string"}
      }
    }
  }
}
```
