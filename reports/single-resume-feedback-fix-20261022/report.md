The checker now requires an explicit --llm-review or --local-only mode. LLM mode loads the private DeepSeek settings, explicitly enables review, and rejects a missing key before extraction. The feedback loop re-enters local recovery, strict section review, schema mapping and source-backed schema audit for pending meaningful spans, required fields or audit findings. Per-pass artifacts and provider attempt records expose execution. No provider output can directly rewrite source or schema values.
