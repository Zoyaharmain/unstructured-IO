# Remaining limitations and approval boundary

- This phase made no live calls. Mock responses confirm the frozen placements and acknowledge audit units; they cannot show DeepSeek instruction-following, actual token consumption, billed cost, semantic completeness or stable real-world behavior.
- The default token guard is a conservative byte-based local policy, not a provider tokenizer or a verified context-window specification. Provider-enabled calibration and envelope/response telemetry need a fresh approval.
- Giant indivisible field items, unsafe source splits or oversized required context remain explicitly unreviewable. Coverage cannot be declared complete in those cases. The ten frozen cases fit the tested guards; this is not a guarantee for all possible resumes.
- Audit coverage covers every configured unit and adjacent record boundaries, not all possible nonadjacent association hypotheses. Scope completeness is not semantic correctness; record-local source support is necessary but insufficient.
- Paragraph reconstruction (D2), uncertain education dates and other unadjudicated findings remain. Both meaningful unresolved spans from the ten-resume baseline persist.
- Source/record ownership is preserved on confirmation. Changed placements still use the existing source-bound global grouping rules; the new crosswalk reports ownership changes but does not certify them or silently realign labels.
- Global budgets apply to an explicitly shared evaluation/run object. Independent API requests have separate scopes; future batch drivers must share a budget and freeze document scope. No old 350 runner or prior paid authorization was reused.
- The section API accepts elements, not original PDF bytes; it binds the inventory and declares the original-byte hash unavailable. The CLI/replay supply that hash.
- No server was started/restarted, no .env key was changed, and no new price or live-call allowance was assumed.

Readiness: offline structural implementation can be reviewed for a small separately approved provider pilot. NO-GO for production scaling, semantic-accuracy certification, or automatic larger processing. Stop here pending explicit paid-run approval and a new call cap. The 56 replay requests were synthetic and are not a proposed invoice or a new authorization.
