Project: TSDBO – Credit Card Payments                                                       Role: Project Manager
Organization: Capgemini

TSDBO is a multi-phase initiative that enables the Transaction Service to retrieve transaction history efficiently.
When a user sends a request, the Transaction Service retrieves the watermark date and queries the Transaction
History Service for transaction history up to that watermark date to verify that the data has been migrated. If the
required data is unavailable, it falls back to the CC Web API. The CoreCard API fetches the data from the primary
database and reconciles it with the reporting database. Secure File Exchange (SFX) then extracts the data from the
reporting database and stores it in Amazon S3, from where the History Data Loader retrieves the data and loads it
into SingleStore.
