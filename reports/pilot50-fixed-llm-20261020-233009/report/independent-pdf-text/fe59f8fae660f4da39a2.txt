          Detailed Critique on DoRight website


Upon reviewing the website, I noticed the following things:
  1. The first thing which I observed was the color palette
     and typography which is consistent throughout the site
     which makes it look more professional and highlights the
     brand identity.
  2. Even though the first impression of the website is usually
     the color theme and look of the site, the content also
     plays a crucial role in grabbing the attention of the
     visitors. The website lacks in detail information related
     to their clients and successful projects, including which
     would result in more registrations of new clients.
  3. Although the colour palette of the website is consistent
     it can use more of visual elements to make the website
     more attractive and engaging for the users.
  4. The website can also incorporate SEO to improve the
     site's visibility in search engine results.
  5. The site performs well on mobile devices, making it
     easier for users to access the website according to their
     convenience.
  6. The subtle effects like animation and hovering on the
     buttons and links makes the site more interactable.
  7. The search bar feature is missing from the website which
     would make it easier to access.
  8. Overall the website is fine, but it can definitely use more
     colour and visual elements to make it more impressive.
