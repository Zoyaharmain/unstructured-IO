Work and education relationships

Edit records below: each record lists span_ids. Required work fields: employer, title, dates. Education: degree, institution, year. For each field add field_evidence: {"employer":["span-id"]}. Values must quote evidence inside that record. For a field genuinely absent use field_states: {"title":"not_in_source"} and field_notes: {"title":"Checked all pages; no title stated"}. Set human_relationship_decision to "approved" only after checking that record. Blank unsupported values block approval. Record counts alone are not validation.
